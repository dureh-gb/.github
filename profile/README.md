# 두레공방 (Dureh Gong-bang)

A small workshop that builds private tools for working across your own computers: Mac, Linux, Windows and phone.

Our rules are simple. Your data stays yours, nothing is collected, and everything runs over the connections you already trust.

The names come from Korean village life, when neighbours worked the fields together. *Gong-bang* (공방) means a workshop.
